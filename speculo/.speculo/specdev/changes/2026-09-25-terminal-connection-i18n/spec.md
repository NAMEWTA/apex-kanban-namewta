# Spec: 连接菜单显示服务器连接文案

- **Spec：** `<Path>{roots.state}/specdev/changes/2026-09-25-terminal-connection-i18n/spec.md</Path>`
- **当前 ADR：** `<Path>{roots.state}/specdev/changes/2026-09-25-terminal-connection-i18n/ADR.md</Path>`
- **当前领域上下文：** `<Path>{roots.state}/specdev/changes/2026-09-25-terminal-connection-i18n/CONTEXT.md</Path>`

## 1. 问题与目标

### 问题陈述

智能体设置的连接菜单项显示未翻译的键名 `terminalAgent.settingsDetails.terminal.serverConnection`。点进该页后，标题已经是「服务器连接」。插件语言为中文时，用户看到的是一截键名，而不是子页名称。

### 目标用户与场景

在桌面端打开 NAND 设置、进入智能体产品、查看二级导航的用户。插件语言分别是中文和英文。

### 成功标准

连接菜单项显示与服务器连接子页相同的名称：中文是服务器连接，英文是 Server connection。页面标题保持这两句，控制台没有新的错误。

### 非目标

不改变服务器下载、离线模式或该页上的其他设置。不调整其余二级导航项的文案。

## 2. 解决方案与外部行为

### 解决方案摘要

连接菜单项改为显示已经存在的服务器连接名称。菜单和子页标题使用同一句中文和同一句英文。

### 主要流程

1. 用户打开设置中的 NAND，进入智能体。
2. 二级导航列出连接菜单项。
3. 插件语言为中文时，该项显示服务器连接。
4. 插件语言为英文时，该项显示 Server connection。
5. 点进该项，页面标题仍是同一句名称。

### 边界、失败与稳定错误行为

插件语言只有中文和英文，不读取 Obsidian 的界面语言。缺少翻译时，现有行为是把键名原样显示；本变更之后，连接菜单项不再走这条回退。

非桌面环境没有智能体设置内容时，保持现有的仅桌面提示，不要求出现连接菜单项。

### 状态转换与不变量

切换插件语言后，连接菜单项和服务器连接子页标题同时变成该语言的那一句。两者不得一个是文案、另一个仍是键名。

## 3. 用户故事

- **US-001**：作为使用中文的用户，我希望连接菜单项显示服务器连接，以便知道它打开的是哪一页。
- **US-002**：作为使用英文的用户，我希望连接菜单项显示 Server connection，以便与页面标题一致。
- **US-003**：作为打开该页的用户，我希望页面标题保持服务器连接或 Server connection，以便菜单和标题不产生第二套名称。

## 5. 范围

### IN

让连接菜单项在中文和英文下显示服务器连接子页的现有名称。

### REUSE

继续使用服务器连接这个名称，以及它已经绑定的中文「服务器连接」和英文 Server connection。二级导航的页面集合和顺序不变。

### OUT

- **OOS-001**：不新增另一套与标题不同的菜单文案。
- **OOS-002**：不修改状态栏加载错误，也不修改设置页窄列。
- **OOS-003**：不改变服务器连接子页里的设置项、默认值或持久化字段。

## 6. 已锁定实现约束

- **DEC-001**：连接菜单项的可见中文是服务器连接，可见英文是 Server connection，并与子页标题使用同一对文案。来源：`USER-DECISION:2026-09-25-连接菜单使用现有文案`。

## 7. 数据、接口与兼容

- **公共接口变化：** 无。设置字段和命令不变，只改变一个菜单标签的可见文字。
- **数据模型与持久化：** 无。
- **兼容要求：** 已保存的终端设置不需要迁移。
- **迁移要求：** 无。
- **发布或运维影响：** 无单独发布要求。

## 8. 非功能要求

- **NFR-001 安全与隐私：** 不适用：不展示新的配置值。
- **NFR-002 性能与容量：** 不适用：只改变一个标签的字符串来源。
- **NFR-003 可用性与可靠性：** 两种插件语言下，菜单都不再显示原始键名。
- **NFR-004 可观测性与运营：** 不适用：该缺陷没有控制台错误，修复也不新增日志。

## 10. 风险、假设与未决问题

### 风险

只断言键表里存在某条翻译，并不能证明菜单读的是那一条。接缝必须读取连接菜单项实际呈现的标签。

### 已采用的低影响假设

对齐文案时复用子页标题已经使用的那一对翻译。验证方式是 AC-001、AC-002 与 AC-003 的文字相同。

### 未决问题

无。
