# NAND 设置导航

**顶部 Tab**：设置页唯一的页面切换，排成一排并铺在内容上方。顺序是首页、看板、编辑器、智能体、同步。
_Avoid_: 二级导航、左侧子页

**首页**：顶部 Tab 之一。用来分别打开或关闭看板、编辑器、智能体。
_Avoid_: 模块设置页、总开关以外的另一套导航

**模块开关**：首页上看板、编辑器、智能体三个独立功能的打开和关闭。关闭后，该领域的顶部 Tab 不再出现。
_Avoid_: 同步

**领域 Tab**：看板、编辑器或智能体在首页打开时出现的顶部 Tab。页内是该领域现有的设置项，不再分成子页。要改这些设置，该领域必须是打开的。
_Avoid_: 子页、左侧菜单

**同步 Tab**：顶部始终保留的 Tab。它不是模块开关，也不能从首页关闭。
_Avoid_: 领域 Tab
